# Profile photos

Drop square images here, named after the profile: `Jhon.png`, `Christine.png`,
`Karan.png`, `Pradeep p....png`, `Akashi.png`, `Satish.png`.

Matching ignores case, spaces and punctuation. Any profile without a file keeps
the generated tint. Suggested size: 256 × 256.

`Satish` is the account avatar used in the Home top bar and the bottom
navigation.
